# Restricciones y límites de la versión PHP

- Solo HTML, CSS, JavaScript puro y PHP 8; sin frameworks ni paquetes.
- Sin base de datos relacional: almacenamiento JSON centralizado por `api/almacen.php`.
- El navegador nunca consulta ni modifica directamente archivos JSON.
- Las solicitudes de pago no mueven dinero: no hay pasarela.
- XAMPP/PHP local sirve para aprendizaje; acceso público requiere HTTPS y refuerzo del servidor.
- Imágenes JPG, PNG o WebP hasta 2 MB.
- Contacto abre el correo del usuario; no envía correo automáticamente.
- Seguimiento es un estado administrativo, no GPS en tiempo real.
- No hay recuperación automática de contraseña ni cálculo de utilidad sin costos registrados.
