# Funcionalidades

## Implementadas
- Sitio corporativo responsive, navegación compartida, páginas Nosotros, Misión/Visión, Contacto y PanelApp.
- Registro de clientes, login/logout mediante sesión PHP y roles.
- Catálogo público; interfaz ADMIN para gestionar productos, precios, stock, estados e imágenes.
- Dashboard de conteos; consulta administrativa de clientes.
- Clientes crean pedidos propios; backend calcula total, verifica y descuenta stock. ADMIN actualiza estados.
- Clientes registran solicitudes de pago sin pasarela; ADMIN cambia el estado.
- Entrega pendiente creada junto al pedido; cliente consulta seguimiento y ADMIN actualiza dirección, fecha y estado.
