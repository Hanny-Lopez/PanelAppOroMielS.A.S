# Restricciones

- Solo HTML, CSS, JavaScript Vanilla, PHP, PDO y MySQL/MariaDB; sin frameworks frontend.
- El navegador no se conecta a SQL.
- Las solicitudes de pago no mueven dinero; no hay pasarela.
- Ejecución prevista en XAMPP local; producción necesita HTTPS y configuración reforzada.
- Las imágenes aceptadas son JPG, PNG o WebP de hasta 5 MB.
- El formulario de contacto abre el cliente de correo del usuario; no envía correos desde servidor.
- La primera versión no incluye administración de entregas ni recuperación de contraseña.
