# Instrucciones de desarrollo

1. Mantener nombres de tablas y estados acordados en `database/panelapp.sql`.
2. Toda salida de API debe usar el formato JSON común y mensajes en español.
3. Consultas SQL con PDO y parámetros enlazados; autorización únicamente en backend.
4. No añadir librerías/frameworks sin aprobación.
5. Actualizar documentación y casos de prueba cuando cambie el comportamiento.
6. No registrar datos sensibles o contraseñas en logs.
