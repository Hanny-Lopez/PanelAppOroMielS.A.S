# PanelApp — Oro Miel S.A.S.

Primera versión con frontend HTML/CSS/JavaScript Vanilla y API PHP + MySQL. Consulta la guía de instalación en [`docs/despliegue.md`](docs/despliegue.md), la API en [`docs/api.md`](docs/api.md) y seguridad en [`docs/seguridad.md`](docs/seguridad.md).

Importa `database/panelapp.sql`, crea el administrador en terminal con `php tools/crear-admin.php` y sirve el sitio desde Apache/XAMPP. No abrir las páginas con `file://`, pues la API necesita Apache.
